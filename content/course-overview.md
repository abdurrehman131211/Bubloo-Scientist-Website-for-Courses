# AI That Actually Works
## Bubloo Scientist Academy — Course 01

### Core promise
Most learners already know that AI tools exist. This course teaches the practical skill they are missing: how to use AI properly.

### The operating model
Prompt → Context → Iterate → Verify → Apply

### Lessons
1. Prompting That Gets Results
2. Context Is the Superpower
3. Iterative Prompting: Don’t Settle for Draft One
4. Research, Fact-Checking & Verification
5. Create Better with AI
6. AI + Coding Without Becoming a Copy-Paste Programmer
7. Build Your Personal AI Workflow

### Learner outcome
By the end, a learner should be able to turn vague tasks into clear AI instructions, supply useful context, improve outputs through iteration, verify important claims, use AI in creative and coding workflows, and create a repeatable personal AI workflow.
